# Project Overview: SV22T1020161 (LiteCommerce)

## 🛠 Technology Stack
- **Framework**: .NET 8.0 (ASP.NET Core MVC).
- **Language**: C# 12.
- **Database**: SQL Server.
- **Data Access (Micro-ORM)**: **Dapper**.
- **UI Framework**: **AdminLTE v4** (basded on Bootstrap 5).
- **Frontend Libraries**: 
  - `flatpickr`: Date picker (Vietnamese localization).
  - `autonumeric`: Formatting money/number inputs.
  - `bootstrap-icons`: System icons.
- **Culture/Localization**: `vi-VN` (Vietnamese) as default.

## 🏗 Project Architecture (Multi-Layer)
Project được chia thành các Layer rõ rệt nhằm tách biệt trách nhiệm:

1. **SV22T1020161.Models**: 
   - Chứa các POCO classes (Entities) và Common Models (Pagination, Search Result).
   - Namespace: `SV22T1020161.Models`.

2. **SV22T1020161.DataLayers**: 
   - **Interfaces**: Định nghĩa các `IGenericRepository<T>` và các Repository đặc thù.
   - **SqlServer**: Cài đặt truy vấn SQL trực tiếp bằng **Dapper**.
   - **Pattern**: Repository Pattern. `BaseSqlDAL` quản lý Connection String.

3. **SV22T1020161.BusinessLayers**: 
   - Chứa các class **Static Service** (như `CatalogDataService`, `CommonDataService`).
   - Nhiệm vụ: Làm cầu nối giữa Presentation và DataLayer, xử lý Logic nghiệp vụ trước khi gọi DB.
   - Các Service này khởi tạo Repository thủ công (không dùng DI ở tầng này theo thiết kế hiện tại).

4. **SV22T1020161.Admin**: 
   - Tầng Presentation (Web MVC).
   - **Authentication**: Cookie-based Authentication.
   - **Configuration**: Thiết lập `ApplicationContext` và Dependency Injection cho `HttpContextAccessor`, `WebHostEnvironment`.
   - **Views**: Sử dụng Razor Pages, Layout chính là `_Layout.cshtml`.

## 🎨 UI Style & UX Patterns
- **Theme**: Dark/Light mode hỗ trợ bởi AdminLTE 4.
- **Input Patterns**:
  - Tiền tệ: Dùng class `.money-input` (autoNumeric).
  - Ngày tháng: Dùng class `.date-picker` (flatpickr).
  - Modal: Dùng cơ chế `open-modal` (custom JS) để load nội dung động vào `#dialogModal`.
- **Search/Paging**: 
  - Form tìm kiếm luôn đi kèm với phân trang.
  - Backend trả về `PagedResult<T>` chứa danh sách Item và tổng số dòng để hiển thị UI phân trang.

## 🗄️ Database Schema & Constraints
Dựa trên file `db.mdx`, hệ thống sử dụng các ràng buộc chặt chẽ để đảm bảo toàn vẹn dữ liệu:

- **Primary Entities**: `Products`, `Categories`, `Suppliers`, `Customers`, `Employees`, `Shippers`, `Orders`.
- **Ràng buộc khóa ngoại (Foreign Keys)**:
  - `Products` tham chiếu đến `Categories` (`CategoryID`) và `Suppliers` (`SupplierID`).
  - `ProductAttributes` và `ProductPhotos` tham chiếu đến `Products` (`ProductID`).
  - `Orders` tham chiếu đến `Customers`, `Employees`, `Shippers` và `OrderStatus`.
  - `OrderDetails` là bảng trung gian giữa `Orders` và `Products` (Composite PK: `OrderID`, `ProductID`).
  - `Suppliers` và `Customers` tham chiếu đến bảng `Provinces` (`ProvinceName`) để quản lý địa lý.
- **Data Types**: Sử dụng `nvarchar` cho chuỗi, `money` cho giá cả, `datetime` cho thời gian và `bit` cho các cờ Boolean (`IsSelling`, `IsLocked`, v.v.).

## 📁 File Structure Map
- `/SV22T1020161.Admin`: Giao diện quản trị (đã hoàn thiện cơ bản bởi thày giáo).
- `/SV22T1020161.Shop`: Giao diện dành cho người dùng (đang trong quá trình phát triển bài tập).
- `/SV22T1020161.BusinessLayers`: Logic nghiệp vụ dùng chung cho cả Admin và Shop.
- `/SV22T1020161.DataLayers/SqlServer`: Nơi viết câu lệnh SQL (Dapper).
- `/SV22T1020161.Models`: Định nghĩa bảng dữ liệu dùng chung.
- `db.mdx`: Script tạo Database và dữ liệu mẫu.
